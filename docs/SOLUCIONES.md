# Cómo consultar las soluciones

Los ejercicios iniciales son ejemplos válidos: deben poder evaluarse aunque todavía no hayas hecho las modificaciones propuestas. Las soluciones son implementaciones de referencia originales de este material, no respuestas oficiales de los profesores.

| Lección | Referencia |
|---|---|
| 01 | [solution.nix](../lecciones/01-lenguaje/solution.nix) |
| 02 | [solution.nix](../lecciones/02-shells/solution.nix) |
| 03 | [solution.nix](../lecciones/03-paquetes/solution.nix) |
| 04 | [solution.nix](../lecciones/04-store/solution.nix) |
| 05 | [soluciones/ejercicio.nix](../lecciones/05-lib-y-puntos-fijos/soluciones/ejercicio.nix) |
| 06 | [soluciones/greeter.nix](../lecciones/06-modulos/soluciones/greeter.nix) |

Lee primero el README de cada lección. Antes de abrir la solución, escribe qué salida esperas y cuál es la línea que debería cambiar. Un resultado correcto sin comprender esa línea todavía no resuelve la práctica.

`checks.nix` en las lecciones 05 y 06 prueba las referencias completas. Que esas comprobaciones pasen no significa que tu intento del ejercicio esté resuelto; compara también tu salida con el objetivo descrito.

El [proyecto completo](../proyecto/README.md) ya contiene todas las piezas para revisar la solución de extremo a extremo.
